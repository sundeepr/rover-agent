## OmniVLA-edge
- Outputs 8 waypoints `[dx, dy, cosθ, sinθ]` in learned metric space (0.1m/unit)
- `WAYPOINT_IDX = 4` — waypoint[4] used for drive command
- Heading: `atan2(wp[3], wp[2])` — uses θ directly (NOT `atan2(dy, dx)`)
- `DT = 1.0`, `MAX_LIN_MM_S = 150`, `MAX_ANG_RAD_S = 1.0`
- Context: 5+1 frames (oldest first, padded if context not full)
- Default weights: downloaded from HuggingFace `NHirose/omnivla-edge`
- Custom weights: `--omnivla-weights <path>.pth` (rover_agent) or `--weights <path>.pth` (omnivla_server)
- Trained custom weights location: `/home/sundeep/workspace/omnivla_training/OmniVLA/runs/omnivla_edge_film/omnivla-edge-film-tuned-best.pth`

## CLIP (ViT-B/32)
- Zero-shot path detection: compares image features to positive/negative text prompts
- `MIN_PATH_POS_SIM = 0.18` — floor below which score is forced to 0.0 (no signal)
- Prompts generated by `prompt_generator.py` (Qwen3:4b via Ollama) from goal text
- State machine: `INITIALIZING → PATH_LOST → NAVIGATING ↔ PATH_LOST`
- `path_threshold` default 0.5 (CLI: `--path-threshold`)

## crop_row_strategy
- YOLO detects plants → split left/right by frame centre
- `left_wall = max(x2 of left boxes)`, `right_wall = min(x1 of right boxes)`
- `gap_cx = (left_wall + right_wall) / 2`
- `error_px = gap_cx - frame_cx`
- `radius = vel / (Kp * error_px)`, clamped ±2000mm, dead zone ±20px
- Falls back to straight if no plants detected
- CLI: `--strategy crop_row --crop-type chilli --yolo-model chilli.pt`
- Lab mode: `--lab-mode` uses yolov8n.pt class 58 (potted plant) for plastic plant testing

## row_centering_omnivla
- Front camera: CLIP path detection + OmniVLA waypoints (identical to clip_omnivla)
- Down camera: YOLO detects plants on either side → same wall-finding as crop_row
- Lateral error from down cam blended into OmniVLA radius:
  `final_ang = omnivla_ang + alpha * centering_ang`
- `centering_gain` default 0.001, `centering_alpha` default 0.4
- `--down-device` (default 1) for downward camera index
- PiP thumbnail of down camera embedded in annotated frame (bottom-right)

## omnivla_server.py
- Persistent TCP server (multiprocessing.managers) on port 5100
- Loads OmniVLA+CLIP once; caches CLIP text encodings per goal string
- Use when running multiple rover_agent sessions to avoid repeated model loads
- `python omnivla_server.py --weights <path>.pth`
- Client connects via `--omnivla-server localhost:5100`

## prompt_generator.py
- Calls Qwen3:4b via Ollama `/api/chat` with `think: false, format: json`
- Returns `{"positive": [...], "negative": [...]}` CLIP prompts
- Falls back to template prompts if Ollama unreachable
- Goal: generate prompts AFTER OmniVLA+CLIP loaded to avoid GPU OOM
